# ShopNest Sales Analytics Dashboard (SkilloVilla Capstone Project)

An interactive Power BI dashboard analyzing sales performance, delivery efficiency, and customer behavior for ShopNest, an e-commerce business, built on a relational dataset of 99,000+ real orders.

## What This Project Does
- Consolidates order, product, customer, payment, review, seller, and geolocation data into a single relational data model (9 linked tables)
- Tracks delivery performance: on-time vs. delayed orders, with delay patterns by category and month
- Analyzes revenue trends across time (Month/Quarter/Year), product categories, and payment methods
- Surfaces top and bottom-rated products by customer reviews
- Provides drillthrough and slicers (State, Year, Category) for self-serve, multi-dimensional analysis across an 11-page report

## Tools & Skills Used
- **Power BI** — data modeling, relationships across 9 tables
- **DAX** — custom measures (Total Sales, On-Time/Delayed Orders, Average Rating, Payment Count) and calculated time-intelligence columns (Month, Quarter, Year)
- Report design: drillthrough, action buttons, slicers, multiple visual types (bar, line, donut, table)

## Key Findings
- ~7.9% of orders (7,827 of 99,441) were delivered late
- Identified which product categories and months saw the highest delay rates
- Surfaced top and underperforming product categories by revenue

## Files

## Note on Data
This project uses a real e-commerce transactional dataset (order, product, customer, payment, and review data) provided as part of a SkilloVilla data analytics capstone assignment.
